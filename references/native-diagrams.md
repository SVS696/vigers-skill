# Нативные диаграммы Вигерса

Используй этот файл только тогда, когда постановке действительно нужна модель:
иерархия требований, процесс, состояния, трассировка, данные, варианты
использования или навигация. Диаграммы передают смысл исходных иллюстраций,
а не их полиграфическое оформление.

## D01. Иерархия требований — стр. 7

```mermaid
flowchart TB
  BR["Бизнес-требования"] --> VS["Концепция и границы"]

  UD -.-> FR["Функциональные требования"]
  SR["Системные требования"] --> FR
  QR["Атрибуты качества"] --> SRS["Спецификация требований к ПО"]
  QR -.-> FR
  IR["Внешние интерфейсы"] --> SRS
  IR -.-> FR
  CON["Ограничения"] --> SRS

```

Waiting --> Cancelled : отменен закупщиком

## D16. Карта диалогов заказа химиката — стр. 70

```mermaid
flowchart TD
  START((Начало)) --> LIST["Список текущих заказов"]
  LIST --> ORDER["Ввод заказываемого химиката"]
  ORDER --> STOCK{"Есть на складе?"}
  STOCK -->|да| CONT["Список контейнеров на складе"]
  CONT --> HIST["История операций с контейнером"]
  CONT --> ADD["Добавить контейнер в заказ"]
  STOCK -->|нет| SUP["Список поставщиков химиката"]
  SUP --> ADD
  ORDER -->|неверный химикат| ERR["Сообщение об ошибке"]
  ERR --> ORDER
  ADD --> MORE{"Заказать еще один?"}
  MORE -->|да| ORDER
  MORE -->|нет| CONF["Подтверждение размещения заказа"]
  CONF -->|разместить| OK["Заказ принят"]
  CONF -->|отменить| LIST
  OK --> END((Конец))
  LIST -->|выйти| END
```
