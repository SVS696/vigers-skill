# Текстовая выжимка и дистиллят

В каталоге опубликованы:

- `book-extract.md` — сконвертированный текст выжимки книги, который
  используется только как редкий fallback;
- `native-checklists.md` — тематические контрольные списки;
- `native-diagrams.md` — текстовые Mermaid- и PlantUML-модели;
- `native-tables.md` — матрицы, словари и классификации;
- `task-template.md` — расширенный шаблон постановки.

Основной исполняемый метод находится в `../SKILL.md`. Сначала используй его,
затем производные справочники и только после этого — `book-extract.md`.

Исходные PDF, FB2, сканы и растровые иллюстрации в репозитории отсутствуют.
