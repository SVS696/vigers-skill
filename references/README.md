# Справочники и локальные источники

В каталоге опубликована переработанная выжимка метода:

- `native-checklists.md` — тематические контрольные списки;
- `native-diagrams.md` — текстовые Mermaid- и PlantUML-модели;
- `native-tables.md` — матрицы, словари и классификации;
- `task-template.md` — расширенный шаблон постановки.

Скилл работает и без этих файлов: он открывает их только для точечного
уточнения.

Если для редкого уточнения нужен принадлежащий вам источник, создайте файл:

```text
references/private/book-extract.md
```

Каталог `private/` не отслеживается Git. Не публикуйте в репозитории исходный
PDF, сканы, извлеченные иллюстрации или полный текстовый слепок источника.
